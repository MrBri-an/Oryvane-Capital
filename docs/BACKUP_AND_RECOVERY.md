# Backup and recovery

Production remains blocked until Supabase database and private Storage backup coverage, retention, encryption, restore objectives, and responsible owners are confirmed. Test restoration in an isolated environment. A restore drill must verify Auth-linked profiles, immutable wallet transactions, audit logs, private receipt ownership, and migration history without mutating production.

Document RPO/RTO, backup frequency, retention, regional constraints, key ownership, restore approval, post-restore reconciliation, and evidence dates before launch.
